# ColdShine Auto Care

Full multi-page React/Vite marketing website for ColdShine Auto Care.

## Pages

- Home
- Services overview
- Dedicated individual service pages
- Reviews
- Our Work
- About
- Contact / Quote

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Routing uses React Router's HashRouter so deep service pages work on GitHub Pages.
